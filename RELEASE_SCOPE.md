# Release scope

This is an evolving supplementary measurement release. The authoritative WAV inventory is
`data/metadata/release_datasets.json`; signed-IQ acquisition records are listed separately in
`data/metadata/auxiliary_captures.json`. Every archive is reconstructable from the hash-verified
small binary parts included in the snapshot. The figure-to-data map identifies the actual source
cohort of each added measurement figure, including the withdrawn upper panels of Figure 15.

Invalid or withdrawn recordings are physically absent. This includes the old wall studies, ten
1587 MHz recordings, the invalid fifth and empty sixth cable recordings, the withdrawn computer
charger ON/OFF cohort and excluded later router campaigns. Original-paper plotting notebooks and
simulated-data figure programs are omitted. Only applicable recorded-data measurement and analysis
sources and the new author-approved supplementary cohorts are included.

The current artifacts cover the released supplementary measurements. They are not represented as
the complete original recognition dataset or a fresh run of the original classifier.
