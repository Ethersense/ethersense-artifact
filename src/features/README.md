# Recorded-data feature analysis

`analyze_ab.py` is the historical environment/target PSD analysis program from the 2026-10-19
revision campaign. It expects the original host workspace and reference archive; those inputs are
being curated and will be uploaded with the remaining batches, and the program's paths are set when
they arrive. Additional verified RF64/Welch, modulation and spectral-structure programs are retained
under `revision_workspace/results/` with their cross-campaign layout intact.

The original-paper plotting notebooks, the simulated-data figure scripts and the full recognition
implementation are being prepared for upload and will be added to this tree.
