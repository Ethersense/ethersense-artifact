# C-VMD

This directory documents Phase I of the recognition pipeline: temporal median filtering, noise
whitening and the constellation-guided variational mode decomposition.

The implementation and its true training/recognition configuration are being prepared for upload.
This directory will be completed with the code, its parameters and an executable specification when
that work is released. See the root `README.md` and `RELEASE_SCOPE.md` for the scope of the current
batch.
