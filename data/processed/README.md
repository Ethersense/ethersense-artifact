# Measured summaries

`cord_lengths_20261101/` holds the confirmed four-record 1/2/3/4 m summaries.
`wall_pairs_20261101/` holds the summaries for the new three wall pairs.

These tables are copied from the prior analyses and describe digital spectra, not classification
accuracy or material insertion loss; the provenance files record the original source paths.

will be added as those recordings are uploaded.
